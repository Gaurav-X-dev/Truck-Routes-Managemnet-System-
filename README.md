# Truck Route Management System

A production-grade transport/logistics management system for a company that operates multiple trucks. 

## Features
- Scalable backend built with FastAPI, PostgreSQL, and PostGIS
- React + Vite + TypeScript frontend
- JWT based role authentication (Super Admin, Admin, Driver, Loading Staff)
- Foundational architecture for future Route Optimization and Loading Plans.
